# Недельный план (TaskPlanner)

Чек-лист задач на неделю: соберите задачи из нескольких списков, отмечайте выполненное по дням недели и следите за прогрессом.

## Возможности

- **Недельная сетка** — задачи раскладываются по дням недели (Пн–Вс) с возможностью перемещаться по неделям
- **Несколько списков задач** — создавайте, редактируйте и удаляйте списки; подключайте и отключайте их одной кнопкой
- **Отметки по дням** — состояние «сделано» хранится отдельно на каждый день и сохраняется в браузере (localStorage)
- **Цвета источников** — наглядная подсветка, к какой категории относится задача
- **Шеринг списков** — публикуйте список по ссылке-токену и подписывайтесь на чужие списки (только для чтения)
- **Статистика** — прогресс выполнения задач за выбранную неделю
- **Бэкап и восстановление** — экспорт/импорт списков, отметок и цветов в один JSON-файл

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite
- Чистый CSS без сторонних библиотек

## Запуск

```bash
npm install
npm run dev
```

Затем откройте `http://localhost:5173`.

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Как это работает

Данные хранятся в виде JSON-файлов в каталоге `public/`:

- `manifest.json` — корневой манифест с начальным набором списков
- `users/<uid>/manifest.json` — список каталогов конкретного пользователя
- `users/<uid>/*.json` — сами списки задач
- `users/<uid>/state.json` — отметки «сделано» по дням
- `shared/<token>.json` — опубликованные для шаринга списки

Каждый пользователь идентифицируется по уникальному `uid` в cookie, поэтому у каждого свои списки и отметки. При первом заходе начальные списки копируются из корневого `manifest.json`.

Запись файлов выполняется через dev-сервер Vite: отдельный middleware (`save-json` в `vite.config.js`) обрабатывает эндпоинты `/__save` и `/__delete`.
